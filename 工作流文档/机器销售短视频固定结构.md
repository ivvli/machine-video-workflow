# 机器销售短视频固定结构

## 适用范围

用于 UV 打印机、标签机、裁切机、压烫设备及其他工业机器的 15-30 秒销售短视频。默认目标是让潜在买家看懂成品、相信机器能做，并通过私信进入打样或咨询。

## 固定叙事骨架

剪辑顺序不能只按生产工序平铺。每条视频先建立：

`产生问题 → 形成猜测 → 口播提前半拍给答案 → 最强画面随后证明 → 产生下一期待`

- 口播答案默认比关键画面落点提前约 `0.5–1 秒`，不得在观众尚未产生问题前提前讲完。
- 每 `1.5–2.5 秒` 至少出现一个新问题、新证据、视觉尺度变化、结果升级或买家价值。
- 正式剪整条视频前，先在帧场制作三个独立的 `0–3 秒` 钩子原型，用户确认后再进入完整粗剪。
- 粗剪先不加字幕和装饰；画面节奏通过后，再加配音、字幕、高亮和声音细节。

逐镜表增加：

| 观众当前认知 | 新问题 | 口播兑现时间 | 画面兑现时间 | 情绪作用 | 下一期待 |
|---|---|---:|---:|---|---|

### 1. 开头：让人停下来

二选一：

- **成品钩子：** 第一帧直接展示最有反差、最接近真实应用的成品，用疑问、误认或结果句制造好奇。
- **人物钩子：** 人物与成品或机器同框，第一句话直接说客户问题、异常结果或订单机会；禁止“大家好，今天介绍一款机器”。

开头只完成一件事：让目标客户愿意继续看。不要同时解释工序、参数和所有卖点。

### 2. 中段：用画面证明

默认顺序：

`打印过程 → 必要的后处理 → 成品效果 → 买家价值`

- 文案说“打印”，画面必须看到喷头、材料或图案正在形成。
- 文案说“裁切”，画面必须看到刀头动作或裁切后的清晰边缘。
- 文案说“压烫”，画面必须看到放置、下压、揭膜或完成动作。
- 文案说“立体、柔软、耐刮”等性质，画面必须有微距、触摸、弯折或真实测试。
- 文案说“多色、多款、小单、换图”，画面必须展示不同颜色、多个图案或电脑换图证据。
- 不要求每条视频展示所有步骤，只保留本条文案真正提到、素材能够证明的内容。

中段核心不是把素材全部用完，而是让每个镜头回答一句话。

### 3. 结尾：人物接住咨询

人物、样品和机器尽量同框。最后一句必须明确：客户找谁、做什么、能得到什么。

优先 CTA：

- `感兴趣，可以私信我打样。`
- `想了解这类工艺，可以私信我。`
- `需要看实际效果，可以私信我安排打样。`
- `想咨询机器配置，可以私信我。`

避免只有“欢迎咨询”“咨询配置”等站在销售角度、客户回报不明确的句子。

## 固定文案风格：犀利反差型

这类机器视频优先使用短句、反差和动作词。语言要像人在现场指着产品说话，不像产品说明书，也不为了“高级”而堆修饰词。

参考爆款时只借文案功能链、观众心理链和证据链；先完成框架适配，再写我方原创口播。不得再以保留对标原句数、语序和节奏的最小替词作为默认方法。夸张语调可以使用，但事实结论仍需画面、测试、数据或用户确认支持。

### 核心写法

1. **用对立制造反差：** 针线与打印、慢工序与快速成型、传统制版与直接换图、看起来与实际上。
2. **短句先行：** 每句话只承担一个任务，先吸引，再揭晓，再证明，最后引导行动。
3. **少解释，多给结果：** 能由下一镜头回答的问题，不在同一句里自问自答两遍。
4. **多用动作词：** 打印、裁切、压烫、揭膜、弯折、换图、打样；少用“赋能、升级、创新解决方案”等空词。
5. **语句必须承接：** 用“这种”“成型后”“再”“遇到”“所以”等必要连接，让整段像自然口语，而不是卖点清单。
6. **结尾回到客户：** 明确说“私信我”，并告诉客户能获得打样、样品、测试或配置判断。

### 推荐心理顺序

`反常识结果 → 一句揭底 → 工序证据 → 订单价值 → 私信回报`

### 风格示例

> 针线还没上场，刺绣效果已经出来了。  
> 靠的不是绣花机，是 GD-6090Pro。  
> 纹理直接打印，沿图裁切，再压到面料，三步成型。  
> 不用制版，多色、小单，换图就做。  
> 感兴趣，可以私信我打样。

借鉴的是短句、对立和克制，不是为了文学感使用生僻词。文案最终必须让机器买家一听就懂。

## 已出现的问题与解决方式

| 已出现的问题 | 具体表现 | 根本原因 | 固定解决方式 |
|---|---|---|---|
| 同一个词连续重复 | “这是打印出来的，第一步打印”；“是绣的，其实一针都没绣” | 只顾交代信息，没有朗读检查 | 相邻两句避免重复核心动词；问句后用新的事实揭底，例如“这种纹理是机器打印出来的” |
| 自问自答过度 | 问完“是不是刺绣”，又连续解释“没有绣、不是绣” | 害怕观众没听懂，重复给答案 | 钩子提出误认，下一句直接说机器或工艺；答案只给一次 |
| 文案像卖点清单 | 每句话单独成立，放在一起不连贯 | 按功能逐条填写，没有心理推进 | 写完后检查“上一句为什么能进入下一句”；按结果、来源、过程、价值、行动重排 |
| 为了凑时长扩句 | 在原句后不断补解释，语句越来越长 | 把“信息多”误认为“说服力强” | 不在原文上机械扩写；先确定一个核心冲突，再重写整段结构 |
| 工序编号浪费时间 | “第一步、第二步、第三步”反复占用配音 | 把说明书语言搬进短视频 | 直接使用“打印、裁切、压烫”三个动作词，由画面承担顺序 |
| CTA 站在销售角度 | “欢迎咨询”“咨询配置” | 没说明联系对象或下一步 | 使用“感兴趣，可以私信我打样”“想咨询机器配置，可以私信我” |
| CTA 过度口语化 | “你把图案发来，我先给你做一个” | 像临场聊天，不符合用户要求的简洁收口 | 统一采用简洁引导式：`感兴趣/想了解 + 可以私信我 + 打样/配置` |
| 卖点没有画面证明 | 说耐洗、换图快、颜色不限，画面只是静态成品 | 文案与素材分开创作 | 每个卖点写出对应证据镜头；没有测试或操作画面就删除或降低表述强度 |
| 过度承诺 | “完全替代传统刺绣”“绝对耐洗” | 追求冲击力，忽略证据边界 | 改成“另一种工艺选择”“呈现仿刺绣效果”；耐洗等性质必须有真实测试依据 |
| 只模仿句子，不模仿逻辑 | 换几个词，仍然是旧文案结构 | 把参考视频当词库 | 模仿参考片的心理推进和证据顺序，不逐字复制，也不简单扩写原文 |
| 文案与画面各说各话 | 说打印时展示成品，说优点时展示人物 | 先写字幕、后随意塞素材 | 先按配音时间戳拆语义，再为每句选择能证明它的镜头，字幕最后叠加 |
| 工序画面太小或太快 | 三个工序塞入三联画，每一步不到一秒 | 为避免闪切而过度压缩画面 | 工序分别全屏展示，每个关键动作至少停留到观众看清 |

## 文案交付前朗读检查

1. 连续朗读两遍，标出相邻句重复出现的名词和动词。
2. 删除问句后重复出现的第二个答案。
3. 删除任何不影响理解的“第一、第二、然后就是、我们这个”。
4. 检查每句是否自然引出下一句，而不是五句广告语并排。
5. 把自己放在客户位置：是否知道这与自己的订单有什么关系。
6. 读到最后一句时，是否明确知道该私信谁、私信后能得到什么。
7. 按实际音色试听；文字看着通顺但读着拗口的句子必须重写。

## 默认时间分配

| 部分 | 15-20 秒视频 | 20-30 秒视频 |
|---|---:|---:|
| 成品或人物钩子 | 2-3 秒 | 3-4 秒 |
| 打印及必要工序 | 6-9 秒 | 10-15 秒 |
| 成品效果和买家价值 | 3-5 秒 | 5-7 秒 |
| 人物 CTA | 2-3 秒 | 3-4 秒 |

## 字幕与画面对齐规则

1. 先确定配音时间戳，再安排镜头，最后叠加字幕。
2. 一句文案对应一个主要画面动作；一句中包含多个工序时，拆成多个字幕节拍。
3. 字幕出现和消失必须跟随对应词语的配音起止时间。
4. 字幕不能遮挡喷头、成品纹理、手部动作、人物面部和机器型号。
5. 每屏优先 6-14 个汉字；长句按语义拆开，不整段铺满画面。
6. 关键词可高亮，但一屏只突出一个重点。
7. 不用三联画压缩三个工序；工序需要看清时，分别全屏展示。

## 默认验收顺序

1. 静音观看：能否只看画面理解结果、过程和咨询动作。
2. 只听配音：语句是否自然连贯，有没有重复、堆词或销售腔。
3. 声画同看：每句话是否正在被当前画面证明。
4. 检查前三秒：目标客户能否马上知道这是什么结果或解决什么问题。
5. 检查动态稳定性：从头到尾正常速度观看，任何非创意需要的手持抖动、突然俯仰、猛推猛拉、主体猛烈跳动、运动方向突变、同一素材时间倒退或切点运动不连续，均退回修改。
6. 检查字幕和配音：中文配音与中文字幕逐字一致；英文字幕与同期中文配音语义对应；字幕、高亮和画面动作跟随对应口播时间。任一不符均退回修改。
7. 检查最后三秒：人物是否自然，CTA 是否明确，样品和机器是否可见；最后至少约 1 秒稳定，不得在相机移动、主体模糊或动作半途结束。
8. 任何画面、字幕、配音或时间线修改后，从第 1 步重新完整验收，不沿用上一版结论。
