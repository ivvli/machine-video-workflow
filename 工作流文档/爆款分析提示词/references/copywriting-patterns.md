# 机器销售常见框架分类

Use this reference only after a reference video's factual copy, audience psychology, and proof chain have been reconstructed. The categories help name a framework; they do not replace sample-specific analysis and are not final-script templates.

| 框架类型 | 文案功能链 | 典型心理变化 | 最低证据要求 |
|---|---|---|---|
| 认知反差 | 误认/旧判断 -> 揭底 -> 工艺证明 -> 价值 -> CTA | `我以为是A -> 原来是B -> 结果可信 -> 对订单有用` | 结果特写 + 实际机器/工艺动作 |
| 客户痛点 | 具体麻烦 -> 损失/门槛 -> 新方案 -> 证明 -> CTA | `这正是我的麻烦 -> 有替代办法 -> 风险可控` | 旧问题的真实场景或已确认事实 + 新方案证据 |
| 结果先行 | 成品结果 -> 来源揭晓 -> 过程 -> 应用/价值 -> CTA | `想要这个结果 -> 理解怎么做 -> 判断适不适合我` | 成品 + 至少一个关键过程 + 应用边界 |
| 效率/产能 | 低效现状 -> 机器动作 -> 可核实变化 -> 买家判断 | `旧流程麻烦 -> 新流程更直接 -> 值得比较配置` | 实际计时、连续动作、产量或经确认的数据 |
| 扩品/订单 | 现有业务限制 -> 新品类/工艺 -> 订单场景 -> CTA | `原业务受限 -> 可以扩新订单 -> 想看适配方案` | 多个真实成品/应用 + 机器能力边界 |
| 设备方案 | 客户问题 -> 判断条件 -> 工艺/设备组合 -> 低风险咨询 | `我不懂怎么配 -> 有清楚判断路径 -> 可以先提供资料` | 材料、尺寸、产量等配置依据 |
| 案例证明 | 真实样品/客户问题 -> 细节 -> 过程或测试 -> 适用对象 | `不是效果图 -> 有物理证据 -> 与我的业务相关` | 来源可核实的样品、测试或案例材料 |

## Classification rules

- Choose one dominant framework. Record secondary mechanisms separately.
- Name the observed psychological transition, not just the category.
- Do not infer efficiency, cost, durability, or ROI without corresponding proof.
- Do not copy the reference wording, sentence count, syntax, or CTA phrase into the downstream draft.
- Pass the extracted framework to `machine-video-preflight`; copy creation happens there.
