# 文案、观众心理与框架提取规范

Use this reference after the factual transcript and shot table exist. Do not infer exact audience thoughts when the copy, comments, or behavior does not support them; mark the item as a hypothesis.

## Six-layer separation

1. `事实层`：what is said and shown, with timestamps.
2. `文案层`：what job each spoken unit performs and what new information it adds.
3. `心理层`：which prior belief, emotion, doubt, or desire changes.
4. `证据层`：what visible action or verified fact supports the claim.
5. `框架层`：the product-neutral persuasion mechanism.
6. `迁移层`：the empty slots the user's product must fill later.

Do not write the user's final copy during layers 1-5.

## Copy-function vocabulary

Use precise jobs such as:

- attention interruption;
- buyer-problem recognition;
- traditional expectation;
- expectation reversal;
- answer/reveal;
- physical proof;
- doubt removal;
- concrete money, process, quantity, or threshold value;
- identity qualification;
- low-risk consultation return.

One unit may have a primary and secondary job, but identify one dominant job.

## Psychology reconstruction

For every meaningful beat, answer:

- What did the likely buyer believe before this beat?
- What emotion or tension appears now?
- What doubt is answered?
- What new question is opened?
- Does the beat move the buyer toward `停留`, `理解`, `相信`, `心动`, or `行动`?

Prefer concrete states such as `以为小单必须开版 -> 发现电脑换图即可 -> 接单门槛下降`. Avoid vague labels such as `产生共鸣` without explaining the changed belief.

## Framework extraction test

A valid framework passes all five tests:

1. Product names, models, creator identity, and original wording can be deleted without breaking the logic.
2. It contains a psychological transition, not only section names.
3. It states what evidence earns each important claim.
4. It identifies concrete buyer value rather than generic `省钱/赚钱`.
5. It records what cannot be transferred because of missing proof, audience mismatch, or original expression.

## Framework handoff schema

```text
参考机制假设：

文案功能链：
打断注意 -> 立起传统预期 -> 打破预期 -> 物理证明 -> 具体商业价值 -> 低风险行动

观众心理链：
原有认知 -> 新情绪 -> 疑虑 -> 信任变化 -> 订单代入 -> 行动意愿

证据链：
首帧结果 -> 机器/工艺动作 -> 细节或测试 -> 应用/订单场景 -> 咨询回报

迁移槽位：
- 我方目标买家：
- 唯一客户问题：
- 唯一核心重点：
- 要立起的传统预期：
- 真实的新答案：
- 可见证明：
- 具体钱/件数/门槛/工序价值：
- CTA给客户的回报：
- 不可写的事实边界：
```

The handoff may classify a common pattern, but it must retain the sample-specific psychological and evidence chain.
