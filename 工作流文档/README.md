# 产品短视频工作流文档总览

这个文件夹保存当前V2自动生产线、阶段执行提示词、两套全局Skill备份、爆款视频参考库、人工阅读资料和发布后复盘规则。

## 1. 唯一正式生产入口

聊天输入“开始”或要求启动、继续完整短视频流程时，以`自动生产线-v2/skills/short-video-autopilot/SKILL.md`为唯一总控。各阶段只读取该Skill指定的`references/`；顶层说明文档用于人工理解或补充细则，不得覆盖V2状态与人工确认门槛。

当前固定流程：

`环境预检 → 对标与素材证据审核 → 15–20秒原创文案 → 文案确认 → VoxCPM2自然表演源 → CosyVoice本人音色转换 → 配音确认 → 剪辑脚本 → 剪辑脚本确认 → 本地剪辑 → 帧场完整检查 → 明确上传授权 → 4K成片 → 封面来源确认 → 上传并停在发布按钮前 → 用户手动发布 → 等待72小时 → 一次正式复盘`

默认比例为9:16，目标受众为潜在客户。禁止ChatCut；最终候选必须进入帧场。制作封面前必须确认使用手帐版还是由用户自行制作，最终发布按钮始终由用户点击。

## 2. V2阶段执行文件

位置：`自动生产线-v2/skills/short-video-autopilot/`

- `SKILL.md`：流程总控和人工关卡。
- `references/workflow-v2.md`：阶段输入、动作、输出和完成条件。
- `references/state-machine.md`：状态转换与禁止越级规则。
- `references/copy-evidence-gate.md`：真实镜头与文案证据门槛。
- `references/copy-prompt.md`：V2正式文案提示词。
- `references/voice-voxcpm-cosyvoice.md`：默认配音链路与验收。
- `references/edit-script-approval.md`：逐镜剪辑脚本和确认门槛。
- `references/framefield-contract.md`：帧场工程、呈现与验收要求。
- `references/cover-template.md`：封面来源确认和手帐版规则。
- `references/publishing-and-review.md`：上传边界、用户手动发布和单次72小时复盘总则。
- `references/retention-policy.md`：四项正式成果和禁止自动整理文件的规则。
- `scripts/`：生产线状态、预检、审批、帧场就绪和成果核验脚本。
- `tests/test_pipeline.py`：生产线自动测试。

## 3. 发布后72小时复盘

- `发布后视频数据复盘AI提示词.md`：单次72小时正式复盘的详细执行提示词，包含账号基线、数据采集、漏斗归因、双评分、留存时间线、评论与询盘、参考视频对照和唯一变量迭代。
- V2中的`references/publishing-and-review.md`规定时间门槛和发布边界；本文件补充详细分析方法。两者均只允许发布满72小时后复盘一次，不设置24小时复盘、7天复盘或周报。
- 正式结果写入当前项目的`review.md`；未满72小时只登记等待状态。

## 4. 爆款分析提示词与参考库

### `爆款分析提示词/`

全局`viral-machine-video-analyzer` Skill的可查看备份，说明如何还原参考视频、提取完整文案、分析句子功能、观众心理、声画证据和可迁移框架。正式执行源位于`~/.codex/skills/viral-machine-video-analyzer/`。

### `爆款视频参考库/`

保存已经积累的样本索引、文案策略、客户问题、证据规则和视频框架。它是分析结果与知识库，不是提示词。内部结构查看`爆款视频参考库/README.md`。

## 5. 机器视频前期与验收

位置：`机器视频前期与验收/`

这是全局`machine-video-preflight` Skill的可查看备份，正式执行源位于`~/.codex/skills/machine-video-preflight/`。它不负责剪辑，负责：

- 确认产品、目标买家、客户问题、主风格和CTA；
- 审计素材、事实和文案证据；
- 把爆款心理与证据框架适配为原创机器销售文案；
- 独立审稿并锁定文案；
- 生成可确认的逐镜方案；
- 检查连续性、字幕、配音交接和自然结尾；
- 对剪辑完成的候选执行最终验收并生成`验收报告.md`。

其中`SKILL.md`和部分reference使用英语，是Codex内部执行指令；`剪辑前方案.md`、`验收报告.md`等交付给用户的内容仍使用中文。备份必须与全局正式Skill保持一致，不能只翻译其中一份。

## 6. 人工阅读资料

- `产品短视频拍摄到剪辑工作流.md`：完整制作方法的人工理解版。
- `文案写作.md`：人工填写文案、证据和逐镜脚本的模板；不是V2唯一正式提示词。
- `机器销售短视频固定结构.md`：机器销售视频结构参考；不是生产线总控。
- `社交媒体发布偏好.md`：ConnectOnion更新门槛、封面选择、上传授权和用户手动发布边界。

## 7. 版本与同步规则

- V2提示词只维护`自动生产线-v2/`中的原件，不创建第二套V2副本。
- `爆款分析提示词/`与`机器视频前期与验收/`是全局Skill的可查看快照。
- 更新全局Skill后，必须同步对应备份的`SKILL.md`、`references/`、`scripts/`（如有）和`agents/openai.yaml`，然后逐文件比较。
- 内容不一致时不得声称备份已更新；工作流内备份不得反向覆盖全局执行源。
