# 文案—证据镜头可实现性门槛

写正式文案前，先审完素材并生成`evidence-matrix.md`。文案和画面双向校准，禁止写完文案后用无关镜头填空。

## 选择路径

- 已有素材且不能补拍：先按文件和时间码盘点真实动作，再写素材能够直接支撑的文案。
- 可以安排拍摄：先按已验证卖点写文案初稿，再把每句话转成补拍清单；拍完复审，画面不达标就重拍或改弱文案。
- 新增素材改变核心主张时，重新打开文案、配音和剪辑脚本确认；只补足原主张证据时，从证据表和剪辑脚本重新确认。

## 必填证据表

文件首行必须写`证据门槛：通过`或`证据门槛：未通过`，随后逐句记录：

| 文案句/主张 | 所需可见动作 | 真实文件与源时间码 | 证据强度 | 处理 |
|---|---|---|---|---|
|  |  |  | 直接 / 辅助 / 无 | 保留 / 补拍 / 改文案 / 删除 |

## 判定

- 核心主张必须有`直接`证据：观众静音看画面，也能判断画面正在展示该主张的对象、动作或结果。
- `辅助`证据不能独自承担数字、成本、利润、耐用性、速度、订单量或工序承诺。
- 人物与机器同框不等于机器证据；整理仪容、拿放未完成、失焦、遮挡、重复动作和无关互动均为废片。
- “没人愿意做”“利润高”等难以直接拍出的判断，应由可见的小批量成品、真实订单场景或已核验数据支撑；否则改成画面能够证明的表达。
- 表中任一核心句为`辅助`或`无`且处理未落实，门槛必须写`未通过`，不得进入文案审稿、配音或剪辑。

## 补拍条目

每条补拍要求写清：对应句子、主体、动作起点、动作完成态、景别、持续时间、机器/产品是否同框、禁用动作和安全结尾。素材到达后连续播放验证，不以单帧代替完整动作检查。
