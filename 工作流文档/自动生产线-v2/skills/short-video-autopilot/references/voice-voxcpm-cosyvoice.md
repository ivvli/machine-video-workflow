# VoxCPM2表演源与CosyVoice 3本人音色转换

## 默认正式链路

`锁定文案 -> VoxCPM2整段自然表演 -> 表演源内验 -> CosyVoice 3 inference_vc转换本人音色 -> ASR与完整试听 -> 用户确认`

- VoxCPM2只负责完整口播的语气、停顿、重音、问句和CTA状态，不把逐句音频拼成全文。
- CosyVoice 3只使用`inference_vc`保留源表演并替换为本人音色，不在转换后人工拉音高或对局部句子变速。
- 默认本人音色参考：`<workspace>/视频工作区/7.28.1仿刺绣/voice/reference_master.wav`。
- 已验证样板：`草稿/配音/8.13仿刺绣_本人音色_20260813/8.13仿刺绣_v2去掉多字_本人音色_可试听.wav`，对应17.78秒帧场确认版。

## 生成步骤

1. 只读取用户已确认的锁定文案；文本或标点发生实质变化时退回文案确认。
2. 用`工具环境/语音试听工具/VoxCPM/generate_thoughtful_performance.py`按全文一次生成自然表演源。提示参考应服务于自然连续表达，不复制特定人物身份。
3. 完整试听表演源，重点检查：首句是否成立、问句是否具有疑问状态、停顿是否有理由、证明句是否落稳、后半段是否赶速、CTA是否完整。
4. 表演源不通过时重新生成；不得靠后期强拉问句尾音、逐句变速或拼接掩盖问题。
5. 使用`工具环境/CosyVoice3/转换音色.py`，以表演源为`--source`、本人参考为`--reference`，整段执行一次`inference_vc`。
6. 转换后完成ASR核对、完整实时试听、音色相似度、解码、时长、采样率、声道、响度和峰值检查。
7. 需要时只做一次整体响度规范化，目标约`-16 LUFS`、真峰值不高于`-1.5 dB`；不得改变局部表演。
8. 只有内验通过才标记为可试听候选并交用户确认。用户确认后登记为正式`voice.wav`。

## 备选边界

MiniMax、Voicebox、CosyVoice直接生成或其他配音方案都不是默认正式链路。VoxCPM2或CosyVoice持续失败、资源不足或结果未通过内验时，先说明问题和建议备选，得到用户确认后才能切换；不得自动回退。
