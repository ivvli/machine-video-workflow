# 启动环境预检

输入“开始”后、分析素材前，一次性检查并生成`preflight.md`。

## 硬检查

1. `source_dir`真实存在，状态文件路径与实际素材来源一致，至少包含一个可读视频。
2. 帧场源码、CLI和项目目录可用；API与界面端口必须成对检查并锁定，默认使用隔离的`4318/3001`。端口被占用时读取服务健康信息并核对工程绝对路径，不能静默连接`4317/3000`安装版、旧工程或不同API对应的界面。把最终API地址、界面地址、工程目录和进程归属写入预检结果。
3. 帧场导出Python可以导入Pillow；记录实际Python绝对路径，禁止运行到导出时才发现缺依赖。
4. VoxCPM2环境、模型和整段生成脚本可用；CosyVoice 3环境、模型、`转换音色.py`与本人参考音频可用。记录实际Python、模型和参考音频路径。不得在生成配音时才首次发现缺模型或依赖。
5. Chrome扩展已连接并允许访问本地文件；抖音创作者中心已登录，核对目标账号。验证码或扫码只能由用户完成。
6. B版3:4封面参考资产存在且可读，作为用户选择手帐版时的候选；预检不替用户决定封面方案。

## 输出格式

每项记录`通过/阻塞`、检测证据、实际路径或账号、修复动作。帧场项还需记录“API端口—界面端口—工程路径”的一一对应关系，并确认自动打开能力可用。所有硬检查通过后才能`preflighting -> analyzing`；否则用`block`保存完整问题清单。
