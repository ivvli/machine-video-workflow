# 剪辑脚本确认契约

配音确认后生成`edit-script.md`，先交用户确认，再开始任何剪辑；最终待确认版本进入帧场呈现。

## 必备内容

- 目标时长、画幅、帧率、配音文件和锁定文案版本。
- 每个镜头的序号、成片时间码、素材文件名、源素材入点/出点、实际画面、对应口播、证据作用。
- 每个镜头的剪辑动作、字幕内容与时间、关键词样式、转场、声音处理和连续性说明。
- 前三秒钩子、结尾状态、素材不足、事实风险和可能需要补拍的内容。

## 确认门槛

提交一份推荐脚本和简短确认摘要。用户确认后运行`approve --kind edit_script`；在此之前禁止使用任何工具开始剪辑。用户退回时保留原因，修改后再次进入`awaiting_script_approval`。

验收整改可以在已确认意图内微调切点、字幕帧和技术参数；改变镜头顺序、核心素材、主张证据或文案对应关系时，必须重新确认剪辑脚本。
