# V2端到端试运行验收

## 启动与状态

- [ ] 聊天输入“开始”可唯一选择待处理素材。
- [ ] 自动创建项目编号和状态文件。
- [ ] 环境预检一次性检查素材路径、帧场端口、导出依赖、VoxCPM2、CosyVoice 3、本人参考音频、Chrome文件权限、抖音登录和账号。
- [ ] 中断后从正确状态恢复，不重复已锁定阶段。

## 五个确认点

- [ ] 文案确认前不生成正式配音。
- [ ] 配音确认前不生成剪辑脚本或开始剪辑。
- [ ] 剪辑脚本包含源/成片时间码、素材、画面、文案、证据、字幕和风险，用户确认前不得使用任何工具开始剪辑。
- [ ] 内部验收后先在帧场打开本地检查稿，用户未明确说“上传”前不得上传。
- [ ] 明确授权上传后才上传，并停在最终发布按钮前。

## 文案与封面

- [ ] `evidence_matrix`逐句记录所需画面、真实素材时间码、证据强度和处理，且写明`证据门槛：通过`后才进入文案审稿。
- [ ] 核心文案无直接画面时已选择补拍或改文案，没有使用无关素材强行匹配。
- [ ] 文案优先55–75字，前三秒不是画面陈述，第一句提出买家问题、冲突、利益或认知反差。
- [ ] 初稿至少删除25%冗余，同一事实不重复解释，CTA只有一句。
- [ ] 制作封面前已确认使用B版手帐人物模板或由用户自行制作；未确认前没有生成封面。
- [ ] 选择手帐版时未使用红黄标签历史版式；选择用户自行制作时未擅自改动其设计。

## 帧场

- [ ] ChatCut未参与剪辑。
- [ ] 最终待确认版本已进入帧场，并与实际待交付文件一致。
- [ ] 最终候选进入帧场及每轮整改后有快照。
- [ ] 自动整改最多三轮并重新完整验收。

## 发布与复盘

- [ ] 用户手动点击发布。
- [ ] 作品ID、链接和时间记录正确。
- [ ] 不做24小时与7天复盘。
- [ ] 满72小时只做一次正式复盘。

## 留存

- [ ] `final.mp4`、`voice.wav`、`copy.md`、`review.md`四项成果存在且非空。
- [ ] 原始素材未移动、未修改、未删除。
- [ ] 旧工作流和旧项目未被修改。
- [ ] 自动流程未移动、改名、删除、清理或重新分类项目文件。

## 覆盖旧流程的门槛

以上项目全部通过，且至少一条真实视频完成从“开始”到72小时复盘的闭环后，才允许提出覆盖旧流程；覆盖仍需用户单独确认。
