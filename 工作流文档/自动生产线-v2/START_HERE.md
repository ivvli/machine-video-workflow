# 短视频自动生产线 V2（并行试运行）

状态：未覆盖旧流程；未迁移旧项目；未授权测试上传或删除。

## 使用入口

1. 将一个新项目的素材放入 `原始素材/待处理/<产品或主题>/`。
2. 在聊天中输入：`开始`。
3. 正常情况下依次确认文案、配音、剪辑脚本、上传动作和封面来源，并在平台最终页面手动点击发布。
4. 剪辑脚本未确认时，不使用任何工具开始剪辑。
5. 剪辑过程可使用合适的本地工具，但禁止ChatCut；最终待确认版本必须进入帧场并与待交付文件一致。
6. 发布满72小时后只做一次正式复盘。

## V2路径

- 默认配置：`config/defaults.json`
- 总控Skill：`skills/short-video-autopilot/`
- 运行项目：`视频工作区/自动生产线-v2/运行中/`
- 完成项目：`视频工作区/自动生产线-v2/已完成/`
- 文件整理：由用户自行处理，自动流程不移动、改名、删除或重新分类项目文件
