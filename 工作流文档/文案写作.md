## 6. 固定写作过程

`一个冲突 -> 情绪入口 -> 传统预期 -> 真实反转 -> 物理证明 -> 具体商业价值 -> CTA回报 -> 朗读精简`

写完逐项回答：

1. 每句话新增了什么？
2. 上一句为什么自然进入下一句？
3. 观众心理是否经过停留、理解、相信、心动和行动？
4. 强结论是否紧跟证明？
5. 商业价值是否落到钱、件数、门槛、工序、人工、订单或配置？
6. CTA是否说清谁来、提供什么、能获得什么？
7. 表达是否原创，而不是只替换对标产品词？
