# 05 文案、心理框架与原创改写方法

这份规则回答四个问题：对标视频的文案怎么推进；观众心理怎么变化；哪些证据托住了结论；怎样把机制迁移到我方产品并写成原创文案。

证据标记：`画面直接证明`、`数据/用户确认`、`可补拍证明`、`仅口头声称`、`不可迁移`。

## A. 对标视频必须拆出的三条链

### 文案功能链

常见结构：

`打断注意 -> 立起传统预期 -> 打破预期 -> 物理证明 -> 具体商业价值 -> 低风险行动`

分析时必须逐句说明功能、信息增量和它给下一句制造的期待，不能只贴“痛点型”“结果型”标签。

### 观众心理链

常见结构：

`原有认知/防备 -> 好奇或痛感 -> 新答案 -> 怀疑 -> 证据解除疑虑 -> 代入订单 -> 愿意咨询`

心理描述必须具体，例如：`以为小单必须开版 -> 看到电脑换图 -> 接单门槛下降`，不能只写“产生共鸣”。

### 证据链

常见结构：

`首帧结果 -> 机器/工艺动作 -> 细节或测试 -> 应用/订单场景 -> 咨询回报`

强结论与商业价值之间必须有物理证明或已确认事实。

## B. 框架提取规则

提取框架时删除：

- 原作者身份、品牌、型号和产品名；
- 原句、独特句法、押韵和标志性节奏；
- 未经我方证据支持的数字、材料、耐用性、产量和收益；
- 只适用于原账号受众的场景和CTA。

框架只保留：

- 每一段承担的说服功能；
- 观众认知与情绪怎样推进；
- 每个重要结论需要什么证据；
- 买家价值属于钱、件数、门槛、工序、人工、订单还是配置；
- 咨询为什么对客户是低风险且有回报的。

如果删除原产品和原句后逻辑不成立，说明提取的不是框架，而是原文摘要。

## C. 框架适配卡

写我方文案前必须填写：

| 框架位置 | 对标机制 | 观众心理 | 我方真实内容 | 事实/画面证据 | 不可越过的边界 |
|---|---|---|---|---|---|
| 打断注意 |  |  |  |  |  |
| 传统预期 |  |  |  |  |  |
| 打破预期 |  |  |  |  |  |
| 物理证明 |  |  |  |  |  |
| 具体商业价值 |  |  |  |  |  |
| 低风险行动 |  |  |  |  |  |

任何关键位置没有真实内容或证据时，先删减、补拍或换框架，不靠更夸张的语气补洞。

## D. 四大核心铁律

1. **单点爆破**：整条只讲一个客户问题和一个核心答案，不堆参数和无关卖点。
2. **夸张情绪钩子**：可以用强烈、夸张的语调放大真实矛盾、痛点、结果或机会；夸张表达力度，不虚构事实。
3. **立预期、打预期、给具体爽感**：先让买家认出传统限制，再用真实新答案打破；价值落到钱、件数、门槛、工序、人工、订单或配置，不用无依据百分比。
4. **低风险精准引流**：说清谁来咨询、提供什么，以及能获得打样判断、工艺路线或配置建议中的哪一种回报。

这四条是写作动作，不是禁词表。

## E. 固定写作过程

1. 确定一个冲突或传统预期。
2. 选择痛点、反差、惊人结果、避坑或订单机会作为情绪入口。
3. 立起买家原有预期。
4. 立刻给出真实的新答案。
5. 用机器动作、成品细节、对比、测试或数据证明。
6. 把变化翻译成具体商业价值。
7. 用有明确回报的CTA降低行动门槛。
8. 连续朗读，删除没有信息增量、不能承接下一句或没有证据的内容。

## F. 原创边界

- 借的是心理推进、文案功能和证据顺序，不是原句。
- 不以保留原句数、语序、句法、节奏或CTA形状为目标。
- 需要多个版本时，版本之间应改变心理入口或商业价值角度，不做同义词替换。
- 已由用户锁定的词和CTA必须逐字保留。
- 历史文案可以复用有效策略，但必须记录客户问题、钩子逻辑和说服顺序是否重复。

## G. 交付字段

| 字段 | 内容 |
|---|---|
| 主参考及分析路径 | 完整参考视频与 `framework.md` |
| 爆款机制假设 | 只写有证据支持的可能机制，不把相关性写成确定因果 |
| 三条链 | 文案功能链、观众心理链、证据链 |
| 框架适配卡 | 我方内容和证据逐位置映射 |
| 四大核心铁律 | 本稿如何具体落实 |
| 最终原创文案 | 口播全文与预计时长 |
| 逐句作用与证据 | 每一单元的唯一作用和对应画面/事实 |
| 历史差异 | 与最近三条同类文案的差别 |
| 事实边界 | 删除、收窄或需要补拍的内容 |
| 独立审稿结果 | `通过`或`退回重写` |
