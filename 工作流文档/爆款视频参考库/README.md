`工作流文档/爆款视频参考库/`

## 目录原则

- 本文件夹只保存整理后的入口和规则，不堆放截图、关键帧和重复版本。
- 单条视频的链接、指标、字幕、逐镜分析和截图继续保存在上一级 `视频分析/日期_视频名称/` 中。
- 新增分析先进入证据档案，验证完成后再把结论登记到本库。
- 自有账号发布后的真实数据统一进入 [发布后视频数据库](../发布后视频数据库/README.md)，不与外部爆款样本混放；至少三条可比视频方向一致后，再更新本库规则。
- 作家风格只是语言层，不能覆盖客户问题、真实证据和产品边界。
- 写或剪新视频时，先从 [06 视频框架风格库](./06_视频框架风格库.md) 选择一个主风格，再选择内容策略和辅助拍法。
