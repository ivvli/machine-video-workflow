# 产品短视频拍摄到剪辑工作流

适用场景：抖音/短视频平台，9:16，优先15-20秒，目标受众默认是潜在客户。证据链确有需要时可以稍微超过，但必须说明原因。

核心原则：先脚本，再拍摄，再剪辑。不要先随便拍一堆素材再后期硬救。

剪辑确认规则：实际剪辑前先提供 1-2 个方案，用户确认后再开始动素材。

当前完整主链路：

`方向确认 -> 对标筛选 -> 对标六层分析 -> 提取framework.md -> 我方素材/事实审计 -> 框架适配 -> 四大核心铁律原创文案 -> 独立审稿 -> 用户锁定文案 -> 逐镜脚本 -> 拍摄/补拍 -> 配音确认 -> 剪辑 -> 验收 -> 交付复盘`

对标视频分析与我方素材审计可以在方向确认后并行进行，但必须在“框架适配”处汇合。没有完成框架适配和证据核对，不进入正式文案。

## 0. 方向、对标、证据与脚本确认

### 0.1 先确认业务方向

- 确认目标买家、购买阶段、唯一客户问题、唯一核心记忆点、平台时长和CTA回报。
- 一条视频只解决一个买家问题，不因为素材多就同时讲多个卖点。

### 0.2 对标视频六层分析

对标分析不只看画面，也不直接换词写我方文案。固定顺序为：

1. 来源、表现与受众适配性；
2. 视频内容和镜头事实还原；
3. 原文案逐句功能、信息增量和承接关系；
4. 观众原有认知、情绪、疑虑、信任和行动门槛；
5. 声画证据与不可迁移边界；
6. 提取不含原产品和原句的文案功能框架、观众心理框架和证据框架。

完整对标分析至少保留 `analysis.md`（事实、原文案、心理和证据）与 `framework.md`（供我方创作读取的干净框架）。高播放只能说明样本值得研究，不能证明某一句文案单独造成流量。

### 0.3 我方素材和事实审计

- 不只概括整段视频，必须指出具体可用区间、用途、选择理由和弃用原因。
- 每个候选时间段必须附一张代表性截图；剪辑脚本优先用截图展示镜头，时间码作为辅助信息。
- 机器文案以用户提供的产品知识为基础；需要补充时再查资料，不写未确认的速度、精度、产量、成本或收益。
- 把每个候选结论标为：`画面直接证明`、`数据/用户确认`、`可补拍证明`、`仅口头声称`或`不可使用`。

### 0.4 框架适配与原创文案

先把对标机制逐位置映射到我方的真实内容和证据：打断注意、传统预期、打破预期、物理证明、具体商业价值、低风险行动。任何关键位置填不出来，先删减、补拍或换框架。

再按四大核心铁律写作：

1. 单点爆破；
2. 夸张情绪钩子，夸张语气和反差，不虚构事实；
3. 立起传统预期、打破预期，并把爽感落到钱、件数、门槛、工序、人工、订单或配置；
4. 低风险精准引流，说明谁来咨询、提供什么、能获得什么结果。

固定写作过程：

`一个冲突 -> 情绪入口 -> 传统预期 -> 真实反转 -> 物理证明 -> 具体商业价值 -> CTA回报 -> 朗读精简`

借鉴的是心理推进、文案功能和证据顺序，不保留对标原句数、语序、句法、独特节奏或CTA形状。文案经过独立审稿和用户单独确认，锁定后才生成逐镜脚本。

### 0.5 逐镜确认

- 脚本的每一镜写明：成片位置、素材截图、原文件与时间段、锁定文案、证据作用、选择理由和衔接方式。
- 中段按“人物/操作 -> 机器过程 -> 成品结果 -> 细节验证”组成证据链，不随机插入空镜和人物。
- 用户确认镜头和锁定文案后，才进入实际剪辑。

## 1. 拍摄前先定 5 件事

### 1. 这条视频给谁看

默认先按“潜在客户”写。

潜在客户最关心的不是机器参数本身，而是：

- 这个东西做出来好不好看
- 能用在哪些产品/场景
- 能不能定制
- 小批量能不能做
- 效果是否可信
- 找这家公司能解决什么问题

### 2. 这条视频只讲一个核心记忆点

一条15-20秒视频不要同时塞太多卖点。

例子：

- “滴胶贴纸可以贴杯子曲面”
- “6090UV 可以做小批量定制”
- “打印、切割、成品一条流程都能做”
- “颜色和厚度可以调”

如果核心记忆点不清楚，前三秒就很难有钩子。

### 3. 前三秒钩子

前三秒不要铺垫，不要介绍公司，不要先讲机器型号。

优先放：

- 成品效果
- 使用场景
- 前后对比
- 正在做出结果的机器动作
- 一个客户能立刻看懂的应用画面

例子：

> 这种立体滴胶贴纸，杯子曲面也能贴。

这句话比“今天给大家介绍 6090UV 打印机”更容易留下人。

### 4. 口播和画面要一一对应

每一句口播都要有对应画面。

| 口播 | 必须出现的画面 |
|---|---|
| 杯子曲面也能贴 | 手把贴纸贴到杯子上 |
| 6090UV 直喷 | 机器正在打印 |
| 打印后轮廓切割 | 切割机/刀头正在切 |
| 立体光泽 | 贴纸近景、反光、厚度 |
| 小批量定制 | 一整版不同图案/多张成品 |

如果口播和画面对不上，观众会觉得不可信。

### 5. 配音、原声、配乐的层级

声音优先级：

1. 人声/配音：最清楚，放最前面
2. 机器原声/环境声：压低，作为真实感
3. 配乐：更低，辅助节奏，不抢人声

产品介绍类视频不要让音乐太炸。音乐要轻快、干净、有节奏，但不能盖住口播。

## 2. 优先15-20秒结构

### 0-3 秒：结果钩子

目的：让潜在客户立刻知道“这个东西对我有用”。

画面：

- 成品特写
- 贴到杯子/礼盒/手机壳的结果
- 机器正在做出成品

文案：

> 这种立体滴胶贴纸，杯子曲面也能贴。

### 3-7秒：告诉客户这是什么

目的：让客户知道产品和能力。

画面：

- 机器全景
- 打印过程
- 操作人员拿着成品

文案：

> 用 6090UV 直喷，图案、颜色、厚度都可以调。

### 7-13秒：证明它怎么做出来

目的：建立可信度。

画面：

- 打印近景
- UV 光/喷头/刀头
- 轮廓切割
- 成品边缘细节

文案：

> 打印后再轮廓切割，边缘更干净，细节也清楚。

### 13-17秒：应用场景或商业价值

目的：让客户想到自己的用途。

画面：

- 杯子
- 礼盒
- 手机壳
- 包装
- 品牌周边

文案：

> 适合品牌周边、礼品贴纸、小批量定制。

### 17-20秒：行动引导/公司标识

目的：收住，不拖沓。

画面：

- 公司标识
- 机器/成品干净画面
- 1-3 秒即可

文案：

> 根道数码打印机工厂，支持定制打样。

## 3. 配音怎么处理

### 默认本人音色配音

正式默认使用：`VoxCPM2整段生成自然表演源 -> CosyVoice 3 inference_vc转换本人音色`。

- 全文一次生成，不逐句拼接。
- 先验收表演源的问句、停顿、重音、呼吸和CTA，再转换音色。
- 转换后完成ASR、完整试听、音色相似度、响度和解码检查。
- 用户确认配音后，才按真实停顿安排镜头和字幕。

### 真人录音或其他配音

真人录音、MiniMax、Voicebox、CosyVoice直接生成等均为备选。需要切换时先说明原因，并由用户确认后使用。

## 4. 配乐怎么处理

产品视频配乐只做三件事：

- 给节奏
- 不抢人声
- 让画面不干

推荐风格：

- 轻快电子
- 干净鼓点
- 工厂/科技感但不压迫
- 音量低于人声

不推荐：

- 太炸的 DJ
- 情绪太悲/太慢
- 唱词明显的音乐
- 节奏跟剪辑完全不匹配的音乐

## 5. 我和你的分工

### 你负责

- 告诉我目标客户是谁
- 告诉我这条视频最想让客户记住什么
- 按拍摄清单补齐素材
- 提供正式 logo 或公司名
- 如果要真人声音，录一版口播

### 我负责

- 判断前三秒用哪个画面
- 把卖点优先拆成15-20秒结构
- 写口播文案
- 判断素材缺什么
- 剪辑、字幕、配音、配乐、结尾标识
- 发现需求漏洞时先提醒你

## 7. 初剪验收

- 从头到尾正常速度完整播放一次；每个切点前后各检查约 1.5 秒，确认没有黑帧、闪帧、跳帧、失焦和主体猛烈跳动。静态关键帧和技术参数不能代替完整观看。
- 不得出现非创意需要的手持抖动、突然俯仰、猛推猛拉、运动方向突变、同一素材时间倒退或切点前后运动不连续；出现即退回修改。
- 转场必须服务叙事或动作连续；运动中的卷材默认使用硬切，避免叠化形成双影。
- 单独检查开头 2 秒、最后 3 秒和最终一帧；最后至少约 1 秒稳定，不得在相机仍移动、主体模糊或动作半途时结束。
- 人物结尾不得停在张嘴最大、眨眼、转头或手势半途；优先保留动作落稳后的短暂停顿。
- 裁切、压烫等相邻关键工序不得连续抢切；上一动作及其结果看清后才能进入下一步。若配音过密，优先精简文案，不压缩证明镜头。
- 多余的 0.5-1 秒优先从重复动作的尾部删减，不从关键动作中间硬切。
- 中文配音与中文字幕必须逐字对应，仅允许标点和排版差异；英文字幕必须与同期中文配音语义对应。
- 字幕、高亮和画面动作必须跟随对应口播时间；为了排版修改字幕文字时，必须同步重做配音或恢复原文。
- 任何修改后都必须从头重新完整验收，不得沿用上一版的通过结论。
