# 重剪与修改模式

适用于已有 `剪辑前方案.md`、已有初剪，或用户明确说“重剪、换镜头、改字幕、改节奏、换结尾”的情况。

## 先读，再问

先读已有方案、可用素材和用户最新反馈。不要把已确认的信息再问一遍。

只确认以下内容：

1. 这次必须解决什么问题。
2. 哪些镜头、文案或时长必须保留。
3. 主风格是否仍不变；若改变，说明旧镜头哪些会失去作用。

## 修改影响表

在更新逐镜脚本前，先列出：

| 改动 | 受影响镜头 | 风格风险 | 处理 |
|---|---|---|---|
|  |  |  |  |

典型风险：

- 成品证据型改成太长的人物解释，会削弱开头的结果冲击。
- 真人讲解型换成不同人物或不同场地结尾，会让收尾像硬拼。
- 换掉一个过程镜头后，原文案可能失去画面证据。
- 缩短时长不能从关键动作中间硬切；优先删重复尾部或精简文案。

## 更新规则

- 不修改的已确认内容保持原样。
- 每个新镜头重新写连续性锚点。
- 若新素材与主风格冲突，标记为“不建议使用”，并给出同风格替代素材。
- 更新后仍以 `待确认：主风格和逐镜脚本` 为剪辑前关口。
