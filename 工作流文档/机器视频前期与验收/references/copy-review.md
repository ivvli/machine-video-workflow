# 独立文案检查

Use this after the writer produces a draft and before any shot-by-shot plan. Review only confirmed direction, evidence, the extracted framework, adaptation card, recent scripts, locked wording, and draft. Do not defend writer intent. Return only `通过` or `退回重写`.

## Critical checks

| Check | Pass condition |
|---|---|
| Sales objective | Topic clearly serves machine or solution inquiries |
| Buyer and stage | One potential buyer at one stage receives useful decision value |
| Single point | The script stays on one confirmed core point |
| First line | Understandable alone, connected to the first frame, and creates a reason to continue |
| First-three-second payoff | Buyer receives supported surprise, relief, desire, risk reduction, or recognition; curiosity alone fails |
| Traditional expectation | The old belief or problem is recognizable without lengthy setup |
| Real reversal | A verified answer genuinely breaks or resolves the expectation |
| Psychology progression | Each unit advances `停留 -> 理解 -> 相信 -> 心动 -> 行动` |
| Information gain | Every unit adds expectation, reversal, proof, buying value, or action |
| Proof | Strong claims are earned by footage, test, data, or user-confirmed facts |
| Concrete buying value | Value is expressed as a real process, threshold, pieces, labor, order, money, or configuration consequence—not empty `省钱/赚钱` |
| Framework fit | Draft uses the extracted mechanism where it matches our buyer and evidence |
| Original expression | Draft does not preserve reference sentence count, syntax, distinctive rhythm, signature phrase, or copied CTA as a target |
| Exaggeration boundary | Energy and contrast may be exaggerated; factual implications remain supported |
| Historical difference | Difference or deliberate reuse of angle is recorded; novelty is not forced |
| Natural brevity | No filler, semantic duplication, empty step-reporting, or product-manual tone |
| CTA return | Viewer knows who should act, what to provide, and what useful result they receive |
| Spoken delivery | Natural aloud and feasible in target duration without artificial speed changes |
| Locked text | User-approved wording and CTA match character-for-character |
| Dual perspective | Both a machine buyer and a scrolling viewer understand why to continue |

## Context rules

- Do not mechanically reject isolated words. Judge their local function, rhythm, evidence, and buyer value.
- A visible transition does not require a spoken transition.
- Repeated process nouns may be necessary; repeated meaning is not.
- A question, contradiction, or mysterious statement without buyer payoff inside three seconds fails.
- Abstract praise fails unless converted into visible or verified meaning.
- If the draft resembles the reference after product nouns are swapped, return `退回重写` and return to framework adaptation.
- If proof is missing, narrow or remove the claim; do not compensate with stronger tone.

## Deletion and chain test

Delete each unit mentally. If result, proof, buying judgment, and CTA remain unchanged, remove it. Then check every boundary: the prior unit must create a reason for the next. A row of independent advertising slogans fails even when each line sounds strong alone.

## Review result

For `通过`, provide:

- buyer-stage and single-point fit;
- framework and psychology fit;
- proof and concrete-value conclusion;
- originality and historical difference;
- estimated duration;
- buyer-view and scrolling-view conclusion.

For `退回重写`, provide:

- exact failing line or structural point;
- failed check;
- whether to repair adaptation, evidence, or wording;
- corrected full script;
- a complete second review.

Do not create a shot plan until all critical checks pass and the user confirms the final copy.
