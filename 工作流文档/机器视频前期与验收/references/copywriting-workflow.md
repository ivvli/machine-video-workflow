# 工业机器短视频文案创作工作流

Use this reference after direction is confirmed, footage evidence exists, and a reference `framework.md` or internally selected framework is available. Create original expression from a verified persuasion mechanism; do not use minimal word replacement.

## 1. Source priority

1. User-confirmed facts, buyer, direction, locked wording, and CTA.
2. Current footage and verified test/data evidence.
3. Customer questions and objections in the project database.
4. Extracted copy-function, psychology, and proof frameworks from a primary reference.
5. Common patterns and one optional language tendency.

Lower-priority material may shape structure or tone but may not override higher-priority truth.

## 2. Required copy brief

| Field | Required decision |
|---|---|
| Business result | Which machine/solution should generate inquiries? |
| Potential buyer and stage | Who buys, and what decision are they making? |
| One question | The only buyer question this video answers |
| One core point | The single answer the viewer should remember |
| Stop reason | Why the first frame and first line interrupt scrolling |
| First-three-second emotional payoff | Surprise, relief, desire, risk reduction, or recognition |
| Traditional expectation | What the buyer assumes is expensive, complex, slow, risky, or low quality |
| Real reversal | What verified fact breaks that expectation |
| Proof chain | Which footage/data earns belief |
| Concrete buying value | Money, item count, threshold, process, labor, order type, or configuration consequence |
| Consultation return | What useful result the buyer receives by acting |
| Factual boundaries | What may not be claimed |

Compare the three most recent comparable scripts. Change angle when the buyer question, hook logic, and persuasion order are substantially repeated; never manufacture novelty with a false claim.

## 3. Consume the reference correctly

Read the transcript for understanding, then work from `framework.md`.

Keep only:

- the function sequence that earns attention and belief;
- the audience's belief and emotion transitions;
- the proof order that current footage can reproduce;
- the type of concrete buying value;
- the consultation-risk reduction mechanism.

Do not keep as a writing target:

- exact wording or signature phrases;
- sentence count, syntax, rhyme, or distinctive rhythm;
- creator identity, product nouns, models, unsupported numbers, or application claims;
- the original CTA phrase merely because it appeared in a high-performing video.

If the framework does not survive removal of the original wording and product, return to reference analysis.

## 5. Four core laws

1. **单点爆破**：focus the script on the confirmed one core point. Do not stack unrelated parameters, company history, or every available benefit.
2. **夸张情绪钩子**：use strong, exaggerated spoken attitude to dramatize a real pain, contradiction, result, or opportunity. Exaggerate delivery and contrast, not facts, numbers, durability, output, or ROI.
3. **立预期、打预期、给具体爽感**：raise the buyer's traditional expectation, break it with a verified answer, then translate the change into concrete money, item count, threshold, process, labor, or order value. Avoid unsupported percentages.
4. **低风险精准引流**：state who should act, what to provide, and what useful result they receive, such as a sample judgment, process route, or configuration recommendation.

These are writing actions, not a forbidden-word list.

## 6. Required writing process

1. **Name one conflict**：the buyer problem or traditional expectation.
2. **Choose the emotional hook**：pain, contradiction, surprising result, pitfall avoidance, or order opportunity.
3. **Raise the old expectation**：make the buyer recognize the familiar limitation.
4. **Break it immediately**：give the verified new answer without long setup.
5. **Earn the claim**：attach an action, detail, comparison, test, or verified fact.
6. **Calculate concrete payoff**：state the change in money, pieces, threshold, process, labor, order type, or configuration; use only available evidence.
7. **Close with consultation value**：make inquiry feel like obtaining a judgment or solution rather than entering a sales pitch.
8. **Read aloud and tighten**：ensure every unit earns the next, adds information, and fits the target duration naturally.

Recommended chain:

`单一冲突 -> 夸张钩子 -> 传统预期 -> 打破预期 -> 物理证明 -> 具体商业价值 -> 低风险行动`

The reference framework may justify small compression or reordering, but never place a strong claim and buying value together without proof.

## 7. Drafting and selection

- Prefer 4-7 spoken units for 15-25 seconds; time the actual read instead of enforcing a fixed character count.
- Give each unit one dominant job: hook, expectation, reversal, proof, buying value, or CTA.
- Let one sentence span several shots proving the same idea. A transition shot may use natural sound or silence.
- When alternatives help, produce 2-3 versions that differ in psychological entry or value angle, not superficial synonyms.
- Select using buyer fit, first-three-second payoff, evidence strength, concrete value, historical difference, and spoken naturalness.
- Preserve only user-locked wording and CTA character-for-character.

## 8. Contextual brevity test

For every unit ask:

1. What new buyer-relevant information or emotion does it add?
2. Why does the next unit naturally follow?
3. Does it advance `停留 -> 理解 -> 相信 -> 心动 -> 行动`?
4. Can the image communicate it without voiceover?
5. Does deletion leave understanding and buying motivation unchanged?
6. Does it sound like a person at the machine, with the intended exaggerated attitude, rather than a manual?
7. Is every factual implication supported?

Do not use a mechanical forbidden-word list. Rewrite in context when a line is empty, repetitive, awkward, or unearned.

## 9. Required writer output

Provide to the independent reviewer:

1. Copy brief and historical-use note.
2. Primary reference and `framework.md` path when available.
3. Extracted copy-function, psychology, and proof chains.
4. Completed framework-adaptation card.
5. Four-core-law check.
6. Candidate drafts and selection reason when alternatives were useful.
7. Selected final script and estimated spoken duration.
8. Each unit's dominant job and proof.
9. Locked wording/CTA comparison and factual boundaries.

The writer must not approve its own script.
