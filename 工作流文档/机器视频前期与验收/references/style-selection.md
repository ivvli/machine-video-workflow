# 风格选择与素材要求

## 选择顺序

1. 先从客户问题判断主风格。
2. 再从现有素材判断是否可实现。
3. 最后选择 0-2 个辅助拍法补证据。

不要因一个漂亮镜头改变已经确认的主风格。

| 主风格 | 适用问题 | 最小可用素材 | 可替代方案 | 不要这样混 |
|---|---|---|---|---|
| 成品证据型 | 效果、材料、小单、工艺真假 | 成品近景 + 一个真实机器动作 + 成品/人物收口 | 没有真人时用成品和机器同框；没有全流程时保留一个最清楚的过程 | 成品开头后插入长人物介绍或参数清单 |
| 真人讲解型 | 应用、边界、现场说明 | 同一人开头/结尾 + 人机同框 + 一个过程证据 | 人物素材短时，只放开头和结尾，中段保持同场景过程 | 主持人开头、纯快闪中段、换人换场地收口 |
| 客户答疑型 | 价格、配置、材料、上手、开模等单一问题 | 一个真实问题 + 一个答案证据 + 适用边界 + CTA | 无人出镜时用问题字幕 + 手部/样品证明 | 同时答多个问题，或用未验证数字回答 |

| 辅助拍法 | 何时选 | 优先画面 |
|---|---|---|
| 工艺细节随拍 | 需要证明机器确实在做 | 喷头、走料、裁切、热压、材料形成 |
| 真实操作记录 | 需要说明容易上手或流程可落地 | 上料、定位、启动、取成品 |
| 手部/材质验证 | 需要证明触感、厚度、边缘、反光 | 捏、摸、揉、弯折、揭膜、侧光微距 |
| 机器运动 | 需要证明连续、旋转、收卷、推进 | 喷头横移、材料旋转、收卷、托板推进 |
| 应用展示 | 需要让客户想象自己的订单 | 上衣、上包装、上杯子、成品展开 |

素材判断必须用：

- `已满足`：已有清楚可用素材。
- `可替代`：缺少理想素材，但存在不改变主风格的替代画面。
- `建议补拍`：现有素材可做方案，但补拍会明显提高说服力；写清动作、景别和用途。
