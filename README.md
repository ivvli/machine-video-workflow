# 机器销售短视频自动生产流程

这是一套面向工业机器、印刷设备、工艺效果和产品解决方案短视频的可复用工作流。它覆盖爆款参考分析、真实素材审计、原创文案、配音、逐镜剪辑脚本、帧场检查、上传边界、封面选择和发布满72小时后的单次复盘。

仓库只保存流程、Skills、提示词、参考库和安装说明，不包含作者的原始素材、项目工程、配音、成片、草稿、账号数据、客户资料、模型权重或本地工具运行环境。

## 当前规则

- 正式视频时长优先15–20秒。
- 默认配音：VoxCPM2生成完整自然表演源，再由CosyVoice 3 `inference_vc`转换目标音色。
- 剪辑脚本必须单独获得用户确认后才能开始剪辑。
- 禁止ChatCut；最终候选必须在帧场中供用户完整播放检查。
- 上传必须得到明确授权；最终发布按钮只能由用户点击。
- 封面制作前必须选择手帐版或用户自行制作。
- 发布未满72小时只等待；满72小时后只做一次正式复盘。

## 仓库结构

- `AGENTS.md`：工作区总规则和人工关卡。
- `工作流文档/自动生产线-v2/`：唯一正式生产线入口、阶段规则、状态脚本和测试。
- `工作流文档/爆款分析提示词/`：可安装的爆款视频分析Skill。
- `工作流文档/机器视频前期与验收/`：可安装的素材审计、文案、逐镜方案和最终验收Skill。
- `工作流文档/爆款视频参考库/`：样本结论、客户问题、证据规则和框架知识。
- `工作流文档/发布后视频数据复盘AI提示词.md`：单次72小时复盘的详细方法。
- `安装说明/`：Skills、帧场、配音和ConnectOnion的安装入口。

详细文件导航见`工作流文档/README.md`。

## 快速开始

1. 克隆本仓库。
2. 按`安装说明/Skills安装.md`安装两套全局Skill。
3. 按`安装说明/外部工具.md`另外安装帧场、VoxCPM2和CosyVoice 3；需要浏览器自动化时再安装ConnectOnion。
4. 在仓库根目录按需创建`原始素材/`、`视频工作区/`、`草稿/`、`成片/`、`日志/`、`工具环境/`和`垃圾/`。这些运行目录默认不会提交到GitHub。
5. 将待制作素材放入`原始素材/`，在Codex新对话中输入“开始”。

## 安全边界

- 不要提交`.env`、API Key、Token、Cookie、浏览器资料、本人音色样本或客户信息。
- 原始素材、配音、草稿、成片、模型和项目工程默认留在本地。
- ConnectOnion内置浏览器每次使用前必须先升级并检查版本；更新失败时停止。
- 工作流不会自动点击最终发布按钮。

## 验证

在仓库根目录运行：

```bash
python3 工作流文档/自动生产线-v2/tests/test_pipeline.py
```

测试通过只代表状态门槛与脚本逻辑正常；正式交付仍需完整播放和人工确认。
