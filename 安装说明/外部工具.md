# 外部工具安装入口

本仓库不重复上传本地剪辑台、模型权重、Python环境或浏览器资料。请从各自项目安装，并把本地路径配置到自己的工作区。

## 帧场

帧场用于本地时间线剪辑、最终候选呈现和完整播放检查。本仓库只依赖它，不重复包含源码：

- GitHub：<https://github.com/ivvli/framefield>

安装后按帧场仓库说明启动本地API和界面。最终待确认版本必须与实际待交付文件一致。

## VoxCPM2

VoxCPM2负责先生成整段、自然且有表演感的配音源：

- 代码：<https://github.com/OpenBMB/VoxCPM>
- 模型：<https://huggingface.co/openbmb/VoxCPM2>

不要把下载的模型权重提交到本仓库。

## CosyVoice 3

CosyVoice 3默认通过`inference_vc`把VoxCPM2表演源转换成目标音色：

- GitHub：<https://github.com/QwenAudio/CosyVoice>

本人音色参考文件只保存在本机，不得进入Git仓库。

## ConnectOnion（可选）

ConnectOnion只用于需要已登录浏览器状态的上传准备或数据读取，不参与剪辑：

- GitHub：<https://github.com/openonion/connectonion>
- 安装：`pip install connectonion`

每次启动其内置浏览器前，必须先在线升级ConnectOnion、记录升级前后版本并检查浏览器命令。升级、联网或检查失败时不得继续使用旧版本。

不要提交API Key、Cookie、浏览器配置或登录日志。
